# Cómo compartir esta entrega con Claude

## GitHub

Repositorio de entrega: https://github.com/Mayra-Prelude/TJ26

1. Conecta este repositorio a Claude, con acceso de lectura si es privado, o descarga **Code → Download ZIP** y descomprímelo.
2. El paquete completo con capturas está en `entrega/FemTech.zip`. En GitHub, abre ese archivo y pulsa **Download raw file**.
3. Pide a Claude que lea `handoff/TRANSFERENCIA-CLAUDE.md` y sigue el texto de `handoff/PEGAR-EN-CLAUDE.txt`, usando el enlace del repositorio o la carpeta descargada.
4. Los skylines del repositorio están en `newsletter/assets/skylines/`; dentro del paquete también están en `IMAGENES/skylines/`.

El acceso desde Claude depende de sus herramientas y permisos. No se ha publicado un sitio web con GitHub Pages.

## Alternativa con Drive

1. Descarga `femtech-pack-completo-claude.zip` y descomprímelo.
2. Sube la carpeta descomprimida a Google Drive, conservando sus subcarpetas. Nombre sugerido: **FemTech — entrega vigente**.
3. En Drive, usa **Compartir → Copiar enlace**. Da acceso de lectura a la cuenta conectada a Claude. No es necesario hacer pública la carpeta si Claude tiene acceso mediante esa cuenta.
4. En Claude, habilita Google Drive para esa conversación, si está disponible. Comparte el enlace de la carpeta y pega `handoff/PEGAR-EN-CLAUDE.txt`, sustituyendo el marcador por el enlace real.
5. Pide a Claude que confirme que puede leer los archivos y descargar las imágenes antes de implementar. El acceso al enlace depende de sus herramientas y permisos.

El enlace de descarga dentro de esta conversación no es una URL pública que Claude pueda abrir desde otra aplicación. Tampoco `G:\My Drive\...` es un enlace compartible. No se ha creado ni subido una carpeta de Drive desde esta sesión.

## Si Claude no puede leer la carpeta de Drive

- En Claude Code, abre directamente la carpeta descomprimida y usa el mismo texto de instrucciones. Esta opción mantiene todos los archivos disponibles en disco.
- En Claude web, si no puede abrir ZIP, adjunta los archivos descomprimidos que necesite y las imágenes. Empieza por la guía de transferencia, los dos bloques GHL, `email-ghl.html`, el código de la agenda y los PNG. Conserva el ZIP como entrega completa.
- No asumas que conectar Drive permite leer todos los formatos o descargar todos los archivos. Si Claude informa de una limitación, usa la carpeta local o los adjuntos.

## Imágenes

Los skylines están en `IMAGENES/skylines/`. Las portadas originales que faltan están descritas en `handoff/IMAGENES.md`, con la ubicación conocida de Drive y referencias de Luma. Si compartes también la carpeta original **FemTech Assets**, pega su enlace en Claude; el paquete no contiene un enlace real a esa carpeta porque no fue proporcionado.

Para el correo final, Claude debe subir las imágenes a la biblioteca de medios de GHL y usar sus URLs HTTPS. El enlace de una carpeta Drive sirve para transferir archivos, no para usarlo como imagen del newsletter.
