## Descargar y compartir

- [Descargar el paquete completo](https://github.com/Mayra-Prelude/TJ26/raw/refs/heads/main/entrega/FemTech.zip).
- Si el navegador muestra el archivo ZIP, pulsa **Download raw file** (la flecha de descarga).
- También puedes usar **Code → Download ZIP** para descargar el repositorio.
- Para Claude, comparte este repositorio: https://github.com/Mayra-Prelude/TJ26 y dale acceso si es privado. Pídele que lea `handoff/TRANSFERENCIA-CLAUDE.md` y `handoff/PEGAR-EN-CLAUDE.txt`.

El paquete incluye los diseños, las instrucciones, los skylines y las capturas de revisión. Las portadas originales pendientes siguen identificadas como pendientes. GitHub muestra el código HTML; para ver el diseño, descarga y abre el HTML en tu navegador. No se ha activado GitHub Pages.

Empieza en [handoff/TRANSFERENCIA-CLAUDE.md](handoff/TRANSFERENCIA-CLAUDE.md).

- Web: 10 actividades, con Lisboa.

- Tijuana: pases individual y dúo; traslados incluidos, comidas aparte.

Las imágenes disponibles y los originales pendientes están en [handoff/IMAGENES.md](handoff/IMAGENES.md). La guía de redacción está en [handoff/COPY-CLARO.md](handoff/COPY-CLARO.md).
